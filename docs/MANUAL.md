# EVOLUTION RUSH 操作マニュアル

見下ろし型のアリーナサバイバルアクションです。**180秒間** 敵の大群から生き延び、**残り30秒に現れるボスを倒せば** クリアです。1回のプレイは約3分です。

## 1. ゲームの流れ

1. 起動するとタイトル画面が表示されます。難易度を選び、**START**（またはEnter / Spaceキー）で開始します。
2. 自動で攻撃しながらフィールドを動き回り、敵を倒して経験値を集めます。
3. レベルが上がると強化を **3つの候補から1つ** 選びます（マウスでクリック）。
4. 残り30秒でボスが出現します。ボスを倒せばクリアです。
5. **HPが0になる**、または **時間切れ** でゲームオーバーです。
6. 結果画面で「もう一度プレイ」または「タイトルへ戻る」を選べます。

## 2. 操作方法

| 操作 | 内容 |
|---|---|
| W / A / S / D、または矢印キー | プレイヤーの移動 |
| マウスの移動 | 狙う方向（NORMAL / HARD） |
| 左クリック | 発射（HARDのみ）、強化の選択、各ボタンの決定 |
| マウスホイール / スクロールバー | 強化選択画面が長いときのスクロール |
| Enter / Space | タイトル画面でゲーム開始 |

攻撃は基本的に自動です。キー操作は移動だけなので、敵の動きと強化の選択に集中できます。

## 3. 難易度

### 操作難易度
| 難易度 | エネルギー弾の狙い方 |
|---|---|
| EASY | 最も近い敵を自動で狙って撃つ |
| NORMAL | マウスの方向へ自動で撃つ（照準補助あり） |
| HARD | マウスで狙い、左クリックで発射（照準補助は弱め） |

### ゲーム難易度
敵の強さ・数・出現の速さが変わります（EASY < NORMAL < HARD）。初めて遊ぶときは **操作: EASY / ゲーム: NORMAL** がおすすめです。

## 4. 画面の見方

- **画面上部中央**：レベル（LV）、経験値ゲージ（EXP）、進化コアの所持数（CORE、最大3個）
- **画面右下**：残り時間（TIME）、撃破数（KILLS）、HPゲージ。HPは緑→黄→赤紫に変わります。ボス戦中は「BOSS PHASE」と表示されます。
- **ボスのHP**：ボスの頭上にゲージが表示されます。
- **赤い円**：ボスの範囲攻撃・メテオの着弾位置の予告です。円の外へ素早く離れましょう。
- **画面が赤く光る**：ダメージを受けました。

## 5. 敵の種類

時間が進むにつれて、新しい種類の敵が現れます。

| 敵 | 特徴 | 対策 |
|---|---|---|
| グラント（紫・基本） | まっすぐ追いかけてくる | 動き続ける |
| ランナー（緑・小型） | とても速いが、体力が低い。プレイヤーより少し速い | 範囲攻撃（衝撃波・回転オーブ）でまとめて倒す |
| シューター（橙） | 距離を取って弾を撃つ | 動き続けると弾を避けられる。近づいて倒す |
| ブルート（赤・大型） | 遅いが非常に硬く、接触ダメージが大きい。倒すと経験値が多い | 距離を保ち、攻撃を集中させる |
| ボス（残り30秒で出現） | 足元に赤い円を出す範囲攻撃 | 円の外へ離れる |

## 6. 攻撃の種類

| 攻撃 | 内容 | 入手 |
|---|---|---|
| エネルギー弾 | 最初から持っている基本攻撃 | 最初から |
| 回転オーブ | 自分の周りを回って敵に当たる | レベルアップで取得 |
| 衝撃波 | 周囲に広がる範囲攻撃 | レベルアップで取得 |
| 雷撃 | 近くの敵に落ちて連鎖する | レベルアップで取得 |
| メテオ | 敵が密集した場所に隕石を落とす | レベルアップで取得 |

## 7. 強化と進化

- 攻撃ごとに、威力・範囲・速度などの **通常強化** があります。
- 通常強化を重ねると **分岐強化** が現れます。
- レベルアップ時に **進化コア** を獲得できます（最大3個）。分岐強化済みで通常強化を2回以上した攻撃は、コア1個を使って **進化** できます。
  - エネルギー弾 → レールエネルギー
  - 回転オーブ → オービタルストーム
  - 衝撃波 → ノヴァウェーブ
  - 雷撃 → チェインテンペスト
  - メテオ → メテオレイン
- エネルギー弾と雷撃を両方育てると、特殊進化 **プラズマキャノン** を選べます。
- 進化は候補の3択に混ざって出ます。条件を満たしても出ない場合は、次のレベルアップでまた抽選されます。

## 8. 攻略のコツ

1. 敵に囲まれないよう、**止まらずに動き続ける** のが基本です。
2. 序盤は攻撃を増やして手数を確保し、中盤から進化コアで1つの攻撃を伸ばすと安定します。
3. 敵は時間とともに増え、硬くなります。ボスが出る前に、攻撃を何種類か育てておきましょう。
4. ボスの足元に赤い円が出たら、すぐに円の外へ離れてください。

## 9. 動作環境・起動方法

- Windows（実行ファイルをダブルクリックして起動）。
- マウスとキーボードが必要です。
- 開発用のデバッグ機能（経験値の変更、倍速、タイマー操作）は、Unityエディタと Development Build でのみ表示されます。通常のビルドでは表示されません。

## 10. 既知の注意点

- 敵が非常に多くなる終盤は、動作が重くなることがあります。
