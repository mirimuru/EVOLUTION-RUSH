# 自己採点メモ（授業の採点基準に沿った整理）

点数は自分で判断して記入すること。ここでは、各項目で説明できる事実と、弱い点をまとめている。

採点基準：10点満点。6点合格、7点良、8点以上優。
項目：ボリューム／作成難易度（自分なりの工夫）／操作性（動作・マニュアル）／面白さ・ときめき

## 1. ボリューム
- 約3分の1回のプレイに、次の要素を実装した。
  - 攻撃5種類（エネルギー弾・回転オーブ・衝撃波・雷撃・メテオ）
  - 各攻撃の通常強化・分岐強化、5種類の個別進化、特殊進化（プラズマキャノン）
  - 敵4種類（基本・高速のランナー・弾を撃つシューター・大型のブルート）が時間とともに出現し、時間経過で強くなる。180秒のタイマー、ボス戦（範囲攻撃あり）
  - タイトル画面、3段階×2種類の難易度、クリア／ゲームオーバー／リザルト
  - 合成BGM（通常・ボス戦）、効果音、ネオン調UI・演出
- スクリプトは約28本。開発の履歴はREADMEの作業履歴に記録している。
- 弱い点：ステージは固定アリーナ1つ。ボスも1種類。

## 2. 作成難易度（工夫点）
- 外部素材を使わず、BGM・効果音・パーティクル・リングをすべてC#のコードで生成している。
- 強化が分岐し、進化コアを使って進化させる成長システム。攻撃の組み合わせで特殊進化に至る。
- 操作難易度ごとに照準の仕組みが変わる。
- メテオは「敵が最も密集している場所」を自動で選んで狙う。
- 敵の登録簿、Materialの共有など、実行時の負荷を考慮した実装。
- 弱い点：授業のデモプログラムとの差を、発表で具体的に示す必要がある（元のデモに何があり、何を自作したかを整理しておく）。

## 3. 操作性
- 移動はWASD / 矢印キーのみ。攻撃は自動なので、初めてでも操作しやすい。
- タイトル画面に遊び方を表示。`docs/MANUAL.md` に詳細な操作マニュアルを用意した。
- 弱い点：Unity上でのコンパイル・動作確認を、提出前に通しで行う必要がある。重い場面や不具合がないか、HARDも含めて確認すること。

## 4. 面白さ・ときめき
- 序盤から強化を選べるテンポの速い成長、進化の瞬間の演出（画面の光・リング・専用音）、ボス戦の緊張感が狙い。
- 弱い点：面白さは主観。友人や家族に実際に遊んでもらい、感想を集めると、発表で説明しやすい。
